# Kochplan

Monorepo für die Kochplan-App. Solo-Projekt, MVP nur für Eigennutzung.

- [`server/`](server/README.md) — FastAPI-Backend (Postgres, Docker Compose, Homelab/Oracle-Deployment). Details und Dev-Setup siehe `server/README.md` und `server/CLAUDE.md`.
- `ios/` — SwiftUI/SwiftData-App, offline-fähig (noch nicht begonnen).
- `web/` — React/TS-Web-App (noch nicht begonnen).
